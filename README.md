# Mark Me for Android

Mark Me is an offline-first personal finance app for Android. It stores your ledger on your device and helps you track income, expenses, transfers, and budgets. You can also import transactions from supported PDF statements and review them before saving.

This repository hosts Android APKs and release notes.

## Download and install

1. Open the [GitHub Releases page](https://github.com/Sathvidhu/Sathvidhu-Mark-Me-Releases/releases).
2. Choose a release and download the APK listed under **Assets**.
3. Open the downloaded APK on your Android device and follow the installation prompts.

Android supports an in-place update when the installed copy and the new APK use the same application ID and signing certificate. If you need to replace a build signed with a different key, first use **Manage → Export full backup**. Restore the backup after installing the new build.

## Prerelease builds

Releases marked **Pre-release** are available for manual testing. Check the release notes for the changes included in each build. The in-app update checker offers newer stable releases and leaves prereleases available for manual download.
